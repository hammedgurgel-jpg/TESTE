Issue tracker

Issues for this repo live in GitHub Issues (hammedgurgel-jpg/TESTE), managed via the gh CLI.

Conventions
Create: gh issue create --title "..." --body "..."
List open: gh issue list --state open
View: gh issue view <number>
Comment: gh issue comment <number> --body "..."
Close: gh issue close <number>
PRs as a request surface

Off. External pull requests are not treated as items in the triage queue. Work is scoped through issues; PRs are just the implementation of an already-tracked issue.
